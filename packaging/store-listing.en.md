# Microsoft Store listing — English

## Product name
PeerWay

## Description

PeerWay moves files from one device to another with a code, without uploading them to the cloud first.

Type the other device's 8-character code or share yours, pick your files, and that's it. Transfers are end-to-end encrypted and, whenever the network allows it, travel directly between the two devices.

It also works on difficult networks: if a direct connection isn't possible (CGNAT, firewalls), PeerWay falls back to an HTTPS relay and shows which method was used.

Built for everyday use
• Send files of any size with a code.
• Add trusted contacts and accept their transfers automatically.
• Discover nearby devices on your local network.
• Send to several people at once.
• Share a temporary web link to receive from a browser.
• Get native notifications when a file arrives.
• Customize the home screen with a layout that fits you.

Private by default
• End-to-end encryption.
• Your codes stay hidden until you choose to show them.
• No ads.
• No account required to get started.

PeerWay is in free beta. The desktop client is open source (Apache-2.0); the server is private to keep the network safe.
